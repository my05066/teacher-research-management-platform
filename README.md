# 教师科研成果管理平台
🏆 中国大学生计算机设计大赛｜软件应用与开发类参赛作品

> 基于 SpringBoot + Vue3 实现的高校教师科研成果管理平台，实现科研成果录入、多级审核、OCR快速填报、「研觉晓」AI智能科研分析、角色权限管控，解决高校科研成果收集繁琐、统计困难、人工审核效率低下的实际业务痛点。

## ✨项目亮点
1. **多类型科研成果统一管理**
支持科研项目、发表论文、专利软著、科研获奖、学术会议、指导学生获奖、其他科研成果七大类成果登记。

2. **OCR图片快速录入【特色功能】**
上传证书佐证图片，通过OCR+AI解析自动提取证书信息，自动填充表单，降低教师填报工作量。

3. **研觉晓AI智能助手【特色功能】**
基于当前登录教师私有科研数据进行科研水平智能分析；严格做数据隔离，教师仅可访问本人数据，保护科研隐私。

4. **完整审核业务流程**
教师提交成果 → 校管理员审核（通过/驳回附带备注），驳回后教师可修改重新提交。

5. **完善权限控制**
- 教师角色：成果录入、个人成果查看编辑、查看审核状态、AI科研分析
- 校管理员角色：成果审核、全局成果统计、用户管理
- 数据隔离：教师无法查看其他教师科研数据

6. **数据库设计规范**
采用逻辑删除、统一审核字段、索引优化；附件材料统一文件路径管理，适配业务扩展。

## 🛠 技术栈
### 后端
- 核心框架：SpringBoot 2.x
- 持久层：MyBatis、PageHelper分页插件
- 工具：Lombok
- 身份认证：JWT令牌认证
- 文件存储：OSS对象存储

### 前端
- 框架：Vue3 + Vite
- UI组件库：Element‑Plus
- 网络请求：Axios
- 路由：Vue‑Router

### 数据库
- MySQL 8.0，字符集 `utf8mb4`

### 第三方能力
OCR图像识别、大模型AI对话、文件上传
